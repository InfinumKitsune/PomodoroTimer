# Pomodoro Timer V.0.5

Currently is hard set to 25 minute focus time and 5 minute rest time.
Long rests are coded to 2.5 times the normal rest and occur every 5th rest.

## Upcoming changes
Adding functionality to the sliders to allow the user to select the focus and rest times as
well as the interval of the long rest times.

Currently there is only one sound for each phase when the phase starts.
Adding a collection of sounds for the user to choose which sound plays at the beginning of
each phase.

Adding in ambeint sound with its own volume control in the settings tab.

## Technologies

Built with standard HTML, CSS, and Javascript
